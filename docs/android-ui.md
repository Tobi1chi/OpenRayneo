# Android Material 3 界面与首次使用引导

版本：0.5.3-dev，2026-10-17。采用精密工具风，使用 Jetpack Compose 与定制的 Material 3 组件。显示行为以 [眼镜协调器](android-state-machine.md) 为准；界面将操作转成原有事件，不自行建立第二套页面状态机。

## 产品规则

- 主导航为“眼镜、导航、助手”；设置和设备诊断作为次级页面。
- 助手中的手机模型与电脑 Codex 是两个独立执行来源。切换来源只改变查看对象，不发送、取消或重发任务。发送按钮明确标注执行位置。
- “停止眼镜跟随”“暂停显示与收音”“停止当前任务”“结束眼镜回答”保持不同作用范围。
- 眼镜输出区展示当前会话最近成功写出的内容；高德通知和待发送布局单独显示。预览不是眼镜截图，也不证明眼镜物理显示成功。
- 音量条只在实际 PCM 接收时显示，使用真实 RMS。等待首包、等待解码、断流、失败分别显示文字，不使用假波形。
- 模型／电脑配置均可跳过。已保存配置不等于模型鉴权或电脑连接通过；保存不会触发模型请求。
- 演示只存在于引导页并明确标注，不修改导航数据、不发送蓝牙指令、不发起模型任务。

## 首次使用流程

| 步骤 | 内容 | 操作与完成条件 |
| --- | --- | --- |
| 欢迎 | 介绍导航、助手和显示控制 | 开始设置；也可“稍后设置”进入主页 |
| 连接眼镜 | 说明唤醒、释放已有连接与系统配对 | 打开设备面板，按需请求附近设备权限；仅 FULL 状态标记已连接，可跳过 |
| 导航通知 | 解释系统授权范围和高德来源 | 打开系统通知使用权设置，返回后刷新状态；可切换三条明确标注的演示指令 |
| 助手配置 | 手机模型／电脑 Codex 两个入口 | 填写模型参数，或导入电脑配置；加密保存后返回引导，不自动执行任务 |
| 准备情况 | 根据真实权限、连接和配置状态逐项显示 | 可选申请后台状态通知；进入主页，不把跳过项目标为完成 |

当前步骤和完成标记使用独立 UI 偏好保存，中途进程退出后可从原步骤继续。“稍后设置”结束自动引导；设置中可重新查看。升级到本版首次显示引导，已有模型凭据与导航设置保留。

权限拒绝不会阻止浏览与配置。永久拒绝附近设备权限时，设备面板提供应用权限设置入口。通知使用权与 App 自身的后台状态通知是两种不同权限，分别说明与申请。

## 页面和信息层级

| 页面 | 信息 | 主操作 |
| --- | --- | --- |
| 眼镜 | 设备卡、连接阶段、当前活动、真实音频状态 | 连接／管理眼镜、进入导航或助手、暂停显示与收音 |
| 设备面板 | 扫描结果、配对说明、连接进度 | 扫描、选择设备、取消连接 |
| 导航 | 深色方向／距离／路名预览、通知最近接收时间、当前眼镜会话状态 | 打开高德、选择通知、恢复或停止眼镜跟随 |
| 通知来源面板 | 高德候选通知正文与当前选择 | 明确选择跟随来源 |
| 助手 | 来源切换、会话消息、流式结果、待回复请求、底部输入区 | 发送／停止任务、手机语音输入、显示／结束眼镜回答 |
| 审批卡 | Codex 请求的具体内容、选项或输入框 | 允许这一次、拒绝或提交回复；不会自动批准 |
| 设置 | 模型、电脑、权限、外观、使用引导、版本 | 进入相应配置或系统设置 |
| 设备与诊断 | 状态、测试通知、音频解码重启、BLE 诊断、日志 | 显式诊断和恢复，避免日常主页堆叠调试按钮 |

导航通知无法解析、移除或读取断开时，预览清除旧转向。最近接收时间仅说明通知的新旧，不代表定位时效。当前原始协议与固定网格仍由已有执行器负责。

## 视觉与交互

浅色使用黑白灰、细边线和小圆角；深色使用中性深灰底。收起宣传标题、大幅设备插画和大色块，主区域直接呈现眼镜输出。绿色主要保留在眼镜内容区域。按钮、底部导航、分段控件、输入框、卡片、进度条、提示和底部面板使用 Material 3。

页面使用系统字体与可缩放字号；主要交互具备文字或无障碍名称，图标按钮保持标准触控尺寸。页面可滚动，键盘展开时隐藏底部主导航并保留输入区。主页面切换保存浏览位置；手机与电脑输入草稿独立。用户向上阅读后，回答更新不强制拉回底部。

配置草稿只保留在 ViewModel 内存中，支持 Activity 重建；密钥不写入 saved-instance-state，也不参与键盘联想。正式保存继续使用 Android Keystore。当前会话展示保留本次界面生命周期内的最近 30 条先前问答，进程退出后不恢复本地聊天记录；电脑已有会话仍由 Codex 恢复。

代码块使用等宽文本；当前没有完整 Markdown 渲染器。语音按钮明确为“手机语音输入”，眼镜 ASR 继续暂停。

## 生命周期调整

浏览界面时，通过 Application 绑定 `BridgeService`，不在首次打开即申请蓝牙权限或启动 connected-device 前台服务。用户实际连接眼镜时才提升为前台服务。ViewModel 在销毁时移除观察者并解除绑定；界面重建不重建连接。

因此，未连接眼镜时的助手使用依赖当前应用进程，不新增长期后台模型任务保证。连接后原有前台服务继续维护眼镜会话。后台状态通知只有前台连接服务运行时才更新。

## 验证边界

本地构建和 Lint 检查；在独立 Android 15 / API 35 模拟器上验证真实 APK 页面，不连接用户的眼镜或模型账户。检查首次进入、步骤恢复、可选配置、引导完成、权限拒绝后的继续使用、深浅色、键盘避让、配置加密保存和页面状态保留。示例模型参数仅存在于测试模拟器，未写入产品默认配置。

用户已完成小米 13 上 0.5.2 的试用并认可本版，通知监听手动恢复与持续补读也有真机日志支持。该反馈不等于每项后台场景或故障路径均已覆盖；0.5.3 自动超时恢复仍待同类系统故障验证。0.4.0 的 39 项协调器／协议测试属于此前验证，本版不将它们重复宣称为新增 UI 测试。

## 0.5.1 内容对齐

`PageSession.writtenContent` 只由当前会话的 `PageSignal.Written` 更新。新的通知或回答先改变目标内容，不提前替换已写出的内容；相同 SID 的中间写入仍如实记录，但只有最新目标写入才触发回答恢复计时。旧会话回执不能覆盖新会话。断线、设备退出或让出控制时清除当前输出预览。

首页、导航页和助手中的眼镜输出共用 `GlassesOutputPreview`。切换期间展示原会话并标明正在切换；新会话首帧写出前显示等待。手机聊天记录和高德最新通知独立保留，不能被当成已经到达眼镜的内容。

导航网格从 `NavigationFrame.render` 生成并逐格绘制，使用发送路径同一份 20×5 字符内容。箭头图案、距离、动作行和右下角 8 格路名一致，不另画 Unicode 方向箭头、不在眼镜预览中展示未发送的完整路名。左前／左后等指令沿用目前眼镜的左转图案与文字动作，不能在手机上虚构更丰富的斜向图案。完整路名另放在高德通知区域。引导演示也复用同一生成器。

预览表现的是逻辑布局。整帧更新前的 U+3000 是已有协议对齐补偿，不额外作为一列绘制。手机字体、行距与固件光学呈现仍可能不同；实时提示页文字自动消失等行为没有屏幕回传确认，因此不声明像素级镜像。

新增 10 项临时检查覆盖写入前后、连续更新中的中间帧、旧会话回执、断线、外部接管、导航／问答切换、回答期间通知更新与路名裁切。构建、Lint 通过；临时测试代码在本阶段结束后清理。真实眼镜视觉对应仍需佩戴核对。

## 0.5.2 通知诊断入口

引导与设置将“通知权限已授权”和“监听服务已连接”分别显示；导航页提供“恢复通知读取”，设备与诊断页同时展示授权、连接、候选数量和最近快照同步时间。无权限时引导系统授权；有权限但读取中断时先尝试应用内恢复，不要求用户反复关闭权限。恢复保持跟随选择与停止意图，详见通知恢复文档。

0.5.3 在小米设备监听失败时增加后台自启动检查提示；自动绑定超时后重建本应用监听绑定，避免仅重复请求启用。真机证据见 [通知恢复记录](android-notifications.md)。
