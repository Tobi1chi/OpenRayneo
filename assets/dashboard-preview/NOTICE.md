# Dashboard preview reference icons

These vector icons are converted from the user-supplied RayNeo AI 1.0.10 APK, assets/flutter_assets/assets/rayneo_v2/images/{dashboard,weather_icon}/, for the matching local dashboard preview. Vendor graphics retain their original ownership; OpenRayneo source licensing does not relabel these graphics. Source SVG geometry and colours are retained in scalable PDF assets.

The mail provider PNGs are copied from the same dashboard directory. The bundled assets/fonts/rn_icon_v2.ttf is the original vendor icon font, used for charging, LifeLog and loading glyphs. It retains vendor ownership. Rendering applies the original preview's green color filter while preserving each graphic's alpha.
